# CodeAlpha_Chatbot

A simple rule-based chatbot built in Python as part of my
CodeAlpha Python Programming Internship (Task 4).

## Features
- Replies to: hello, hi, how are you, what is your name, help, bye
- Shows a helpful message for anything it doesn't understand

## How to Run
1. Install Python 3
2. Run: `python chatbot.py`

## Concepts Used
functions, if-elif-else, while loop, input/output
